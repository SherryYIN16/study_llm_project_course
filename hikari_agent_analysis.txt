### Hikari Agent 项目功能解析文档

Hikari Agent 是一个基于智能体（Agent）的金融研究与自动化报告生成系统，旨在通过 AI 实现投研工作的自动化。

---

#### 1. 项目核心定位
它是一个端到端的投研自动化平台，其核心逻辑是“AI 化投资银行分析师”。它通过整合金融数据源、利用智能编排与大模型分析能力，将原始财务数据转化为专业的研究报告。

#### 2. 系统流程概述
*   **输入 (Inputs)**:
    *   用户输入的任务需求（如：行业财务分析）。
    *   目标股票或行业的标识符（代码）。
    *   从金融接口 (AkShare) 实时抓取的财务、市值、估值指标。
    *   预定义的报告结构模板与投研逻辑指令。
*   **核心逻辑 (Pipeline)**:
    1. **数据收集**: 通过 src/data_sources 模块调用 AkShare 等接口获取原始财务数据。
    2. **流程调度**: 引入 LangGraph 编排工作流，定义从背景调查、任务规划到调研执行的逻辑节点，确保分析严谨且逻辑闭环。
    3. **智能分析**: 接入 DeepSeek 大模型作为分析引擎，应用专业的投研提示词模板，处理并提炼数据价值。
    4. **成果封装**: 将 AI 生成的结构化洞察，利用 Word 模板引擎生成标准化研究文档。
*   **输出 (Outputs)**:
    *   专业投研报告 (Word .docx 格式)。
    *   中间分析总结 (Markdown 文件)。
    *   部分功能模块 (Podcast) 可输出语音播客音频。

#### 3. 架构优势
*   **自动化投研**: 极大降低了人工搬运数据和初步财务梳理的成本。
*   **逻辑可控**: 使用 LangGraph 构建的有向图工作流，比简单的 LLM 对话更具有确定性和可回溯性。
*   **模块化扩展**: 通过 MCP 工具与独立的功能节点设计，系统可以方便地接入新的数据源或分析维度。

---
总结：Hikari Agent 不仅是一个工具集，而是一个自动化的投研流水线，通过将分析师的思维模型“代码化”和“Agent 化”，实现了金融分析的规模化产出。
