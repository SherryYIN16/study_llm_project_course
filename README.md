# Hikari Agent: 智能投研自动化流水线

Hikari Agent 是一个基于 LangGraph 的智能体（Agent）自动化金融投研平台，通过整合金融数据源、利用智能编排与大模型分析能力，将原始财务数据转化为专业、标准化的研究报告。

## 🚀 核心价值
告别繁琐的金融数据搬运与初步财务梳理，Hikari Agent 充当您的“AI 投研分析师”，为您提供具备投资参考价值的结构化洞察。

## ✨ 核心能力
- **自动化金融分析**: 从数据抓取到报告撰写的端到端全自动流水线。
- **智能工作流编排**: 基于 LangGraph 的有向图工作流，确保投研过程严谨、可回溯。
- **专家模型集成**: 接入 DeepSeek 大模型，结合金融投研 Prompt 模板，提取数据背后的深度洞察。
- **MCP 服务架构**: 标准化 MCP 服务接口，方便 Agent 快速调用与扩展。

## 🛠 技术栈
| 组件 | 说明 |
| :--- | :--- |
| **LangGraph** | 复杂工作流编排与逻辑节点控制。 |
| **DeepSeek AI** | 核心推理大脑，负责逻辑分析与投资建议生成。 |
| **AkShare** | 实时金融数据采集源。 |
| **FastMCP** | 标准化金融工具服务接口。 |
| **Python** | 业务逻辑、分析逻辑与报告封装。 |

## 📂 项目模块结构
| 路径 | 功能说明 |
| :--- | :--- |
| /src/graph/ | 定义了投研任务的核心工作流节点与状态流转。 |
| /src/data_sources/ | 封装了 AkShare 等金融数据采集逻辑。 |
| mcp_server.py | 金融分析工具的 MCP 服务端，负责数据与 AI 桥接。 |
| 	emplate.py | 投研逻辑的 Prompt 提示词模板与结构定义。 |
| /tmp/ | 存储运行时的中间数据与 Markdown 报告缓存。 |

## 💡 系统工作流
1. **数据收集**: 调用 MCP 获取财务、市值等指标。
2. **逻辑分析**: Agent 执行背景调查、需求解析，触发大模型进行深度分析。
3. **成果产出**: 系统自动将结论封装为标准 Word 投研文档。
